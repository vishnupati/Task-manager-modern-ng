Angular 21+ @Component Decorator

What is it?

@Component is a decorator that tells Angular this is a component.

How many properties?

Angular has 20+ optional properties, but projects use only 5-8 typically.

Which are required?

selector and template/templateUrl - everything else is optional.

Modern approach

Use standalone: true in Angular 14+ - better than NgModule.

⚡ Quick Reference

📌 Always Use:

  • selector: Component tag name - 'app-my-comp'
  • template/templateUrl: Where your HTML is
  • standalone: true - Modern way (Angular 14+)
  • imports: If using other components/directives

⚙️ Commonly Use:

  • styleUrl/styleUrls: CSS file path
  • providers: To inject services
  • changeDetection: OnPush - Better performance

🎯 Special Cases:

  • host: Control host element
  • encapsulation: Control CSS scope
  • viewProviders: Only for child components
  • animations: If you need animations
