Web Model Context Protocol Integration

Exposing structured client-side tools directly to AI browser models using @mcp-b/webmcp-polyfill.

What is WebMCP?

WebMCP is a W3C extension of the standard Model Context Protocol. It allows this web application to register JavaScript functions as tools in the browser. When an AI agent visits this page, it can query and run these tools directly—enabling it to read, create, and manage tasks natively in the client-side state without web scraping.

🛡️ Registered Agentic Tools

These functions are exposed to the AI model using navigator.modelContext.registerTool().
